# 春物 GAL 通用能力回灌记录（2026-09-10）

本次只回灌能够服务其他角色卡的运行时能力。春物人物、GAL 输出契约、背景/立绘资产、经济系统、手机内容、关系数值和专属世界书没有进入模板。

## 已同步

- 分支安全记忆：重 Roll、改写或删除消息时，按消息 ID 清理被替换分支的总结、向量和失败队列；早期楼层与玩家手工记忆保留。
- 最新回合增量索引：普通生成只索引最新完整用户/助手回合，手动补录才扫描全历史。
- 向量文本投影：GAL、工具、状态和思考标签在 embedding 前清洗，主叙事历史仍保留原始结构。
- 无默认库存截断：`maxVectors: 0` 表示不主动裁掉旧向量；导入仍保留 50,000 条安全阈值。
- 召回诊断：记录总量、近期排除量、可召回量、最高相似度、阈值和命中数量；单轮注入预算最高 30,000 字符。
- 后台巡检默认关闭：正常回复按层增量索引，玩家需要检查历史缺口时再手动巡检。
- 主副模型监视隔离：只有 `narrative` 路线拥有主叙事浮窗；总结、状态、生图等后台路线不能覆盖它。
- 世界书编辑：内置条目支持本地覆盖、启停和恢复，玩家条目支持新增、编辑和删除。
- RP-Hub 预设：同步至 RP-Hub 1.8.9（commit `b409ca6`）的 17 项官方默认预设，保留时间戳、去 User 中心化和新版 COT。

## 有意不同步

- 春物 `GAL_SCENE`、`GAL_CAST`、`GAL_LINE` 等格式契约；模板只提供可承载这些协议的通用层。
- 春物的状态副模型、联系人、关系、地图、米团、相机衣装和视觉资产解析。
- 春物专用的 1600–2400 字正文要求及 COT 改写。
- 阿里云/GitHub 资产源与域名策略。模板不绑定任何具体部署。

## 派生卡注意事项

向量和总结是二选一的长期记忆模式。`vectorKeepFloors`/`summaryKeepFloors` 只决定近期原文窗口；`vectorRecallMaxChars` 决定单轮最多注入多少向量正文；`maxVectors: 0` 不代表每轮全部注入。派生卡必须使用独有 `storagePrefix`，否则不同卡会共享本地聊天与记忆。
