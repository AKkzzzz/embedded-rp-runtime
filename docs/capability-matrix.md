# 宿主能力矩阵

| 能力 | RP-Hub 内运行 | 独立预览 |
|---|---|---|
| 读取模型设置 | 同源 `RPHubDB` | 可注入 mock |
| 模型列表 | OpenAI 兼容 `/models` | mock |
| 主模型生成 | OpenAI 兼容流式请求 | mock |
| 停止、继续、重生成 | 卡内会话引擎 | 卡内会话引擎 |
| 编辑、删除、清空 | 卡内会话引擎 | 卡内会话引擎 |
| 模型 route | 当前/质量/平衡/快速/变量模型 | mock |
| 向量嵌入 | 继承 RP-Hub embedding 配置，卡内 IndexedDB | 可关闭或 mock |
| 修改宿主世界书 | 不支持 | 无 |
| 卡内世界书编辑 | 支持 | 支持 |
| 卡内持久状态 | canonical 与偏好使用 localStorage，向量/重试队列使用 IndexedDB/localStorage | localStorage |

## 卡内插件能力

插件默认关闭，由卡或用户显式启用：

- 时间线、检查点与回滚；
- RPG 状态与白名单命令；
- 浮球变量查看器；
- 动态 Lore；
- WebLLM 本地适配；
- 音频、视觉效果和 Live2D 探测；
- 随机骰子工具。

这些能力在卡内运行，不依赖父页面注入。未提供本地模型、媒体或 Live2D 资源时，插件只报告不可用并保持纯文字路径。

## 降级原则

RP-Hub API 设置不存在或不完整时，运行时保持单舞台与本地数据可用，但生成操作明确报错；不会猜测默认 Key，也不会把请求偷偷转交给主聊天楼层。

`triggerSlash` 只保留为宿主意图兼容能力，不参与卡内会话主路径。
