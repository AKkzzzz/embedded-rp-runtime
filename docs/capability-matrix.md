# 宿主能力矩阵

| 能力 | RP-Hub 内运行 | 独立预览 |
|---|---|---|
| 读取模型设置 | 同源 `RPHubDB` | 可注入 mock |
| 模型列表 | OpenAI 兼容 `/models` | mock |
| 主模型生成 | OpenAI 兼容流式请求 | mock |
| 停止、继续、重生成 | 卡内会话引擎 | 卡内会话引擎 |
| 编辑、删除、清空 | 卡内会话引擎 | 卡内会话引擎 |
| 模型 route | 当前/质量/平衡/快速/变量模型 | mock |
| 向量嵌入 | 尚未实现 | 可关闭或 mock |
| 修改宿主世界书 | 不支持 | 无 |
| 卡内世界书编辑 | 支持 | 支持 |
| 卡内持久状态 | localStorage；后续长数据迁移 IndexedDB | localStorage |

## 降级原则

RP-Hub API 设置不存在或不完整时，运行时保持单舞台与本地数据可用，但生成操作明确报错；不会猜测默认 Key，也不会把请求偷偷转交给主聊天楼层。

`triggerSlash` 只保留为宿主意图兼容能力，不参与卡内会话主路径。
